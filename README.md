## Overview

This project develops a rigorous stochastic model of a limit order book (LOB), progressing from a simple Poisson birth-death process to a fully calibrated coupled Hawkes model. The work covers three main areas:

1. **Modelling** — Poisson queues, diffusive approximation, Inverse Gaussian law, Hawkes processes, coupled bid/ask dynamics, and price evolution across four limit levels.
2. **Rare event estimation** — Monte Carlo, AMS splitting, and exponential importance sampling for flash-crash probabilities.
3. **Calibration** — Maximum likelihood estimation of Hawkes parameters, validated on Bitcoin Black Thursday (March 2020) data.

## Key Results

- **Hitting time distribution**: confirmed to follow an Inverse Gaussian law under negative drift, with closed-form mean and variance matched by simulation.
- **Hawkes coupling**: mutual excitation between bid and ask sides creates asymmetric flash-crash probabilities; stopping time distributions differ significantly between the two sides.
- **Rare event estimation**: AMS splitting achieves a 7× reduction in coefficient of variation compared to direct Monte Carlo at equivalent sample sizes. Importance sampling provides independent validation.
- **Calibration**: MLE on Bitcoin Black Thursday tick data recovers Hawkes parameters consistent with the theoretical model; simulated order book dynamics match the empirical volatility signature.
